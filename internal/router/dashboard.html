A group is a preference, never a constraint: the router walks the members in order and takes the first one it can serve, and falls back to automatic routing when none of them qualify. A relay is another discrimen whose fleet this one may route to. It expands into one backend per model the other router publishes to this key, and their measured quality, capacity, context and capabilities are imported rather than benchmarked again here. The name prefixes those backend ids, so keep it short.
