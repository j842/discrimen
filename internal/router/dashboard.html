New group

A group is a preference, never a constraint: the router walks the members in order and takes the first one it can serve, and falls back to automatic routing when none of them qualify. Members are model ids, aliases or backend ids, resolved per request, so listing something you have not stood up yet is legitimate.

Add a relay

A relay is another discrimen whose fleet this one may route to. It expands into one backend per model the other router publishes to this key, and their measured quality, capacity, context and capabilities are imported rather than benchmarked again here. The name prefixes those backend ids, so keep it short.
Point it at a router you run. The values it reports are adopted as measured, which is the right trade between two halves of one fleet and the wrong one for a stranger's endpoint — for those use Providers, which measures what it is told.
